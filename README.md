A single-line fortune cookie message for an AI agent, in the voice of a fortune slip: a warning about the agent's own memory — the one fact it is most certain it saved is the one that was never written down.

## Run it

```sh
python3 main.py
```

This writes the fortune (89 characters, one line, no trailing newline) to `/output/entry.txt`.
